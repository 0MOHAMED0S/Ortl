# Wartil (ورتل) - Quranic E-Learning Platform 📖✨

## Description

Wartil (ورتل) is an online Quran learning platform that connects students with certified Quran teachers through live video and audio sessions.  
The platform provides smart scheduling, secure package subscriptions, real-time communication, cloud recording, and a gift-card system for sharing learning sessions.

### Key Features
- Live 1-on-1 Quran sessions  
- Teacher discovery and booking  
- Secure package subscriptions  
- Gift-card learning packages  
- Session recordings  
- Real-time notifications
